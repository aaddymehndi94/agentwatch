# AgentWatch app (phone PWA)

**Scope and mode:** the whole installable app: Inbox, Session, Pair, Settings. Mode: Operate. Phone first (390×844),
one hand, often outside or in the dark; desktop browsers get the same app centred.

**Job:** see in one glance whether an agent is blocked and for how long. Then approve, deny, answer or reply safely,
read what the agent said in properly formatted text, and put the phone away. Proof is the exact command, file or
question shown before the decision, never a summary of it.

**Decision round:** the owner rejected the previous "kitchen ticket rail" world as dated ("built in the 80s") and
pinned the replacement in their own words: "modern, futuristic and perfect", with formatted agent responses. Pinned
direction beats the roll: the concept roll dealt for the previous world (seed in FORM) was overridden by the owner's
pinned words, with no reroll; built code-led (Operate surface).

## Direction contract

THESIS: A pager that feels like current premium software (the craft bar of Linear, Raycast and iOS system apps), not
a dashboard of equal cards. One sentence at the top answers "does anything need me?", blocked work sits directly under
it with its proof, and each session reads as a conversation rendered like a modern chat app.

OWN-WORLD: Night-sky glass. Dark-first near-black blue ground (#05060a) with a light twin (#f2f3f7) via light-dark().
Geist and Geist Mono, self-hosted. Cyan-to-violet brand pair; warm heat (amber → orange → red) means "waiting on you",
cyan means working, violet means idle, green means online/applied. Inverted pill primary (white on dark, ink on light),
24px-radius inset lists, frosted sticky bar, Markdown with highlighted code.

STORY: Pocket buzzes → open → "Claude needs you · Waiting 4m" over a warm sky; the card shows the exact command with
Deny/Approve at thumb height. Approve: the card settles, the sky cools to "All clear", phone back in pocket. Later, tap
a session to read the agent's reply as real Markdown and send a follow-up.

FIRST VIEWPORT: Frosted bar (mark + AgentWatch, "2 of 3 online" pill, settings). Status sentence at 36px with a sub
line (longest wait, working/idle counts). Request cards stacked full-width under it: icon tile, "Claude needs
approval", project · user@host, heat-coloured timer pill, the literal proof block, Deny | Approve. Then sessions
grouped by user@host in inset lists: state orb, project, agent · age, state word + two-line plain-text preview.

FORM: owner-pinned "modern, futuristic"; standing canon at premium-app craft, with two signature moves: the ambient
sky (top-of-screen light that is cool when calm and warms when anything waits) and the live edge (a slow-turning
heat-coloured light around each waiting request). State orbs: orbiting arc while working, ping while it needs you.
seed:7abff6d86f882161 (dealt for the previous world; overridden by the owner's pinned direction)
